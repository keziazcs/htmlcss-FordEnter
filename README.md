# Portal de Lançamento · Ford Ranger 2026

Site de lançamento da Ford Ranger 2026 feito em **HTML e CSS**. Desafio 04 da trilha de Front-end do **Ford Enter**.

## Páginas

- **Home** (`index.html`): destaque da nova Ranger
- **Lançamento** (`lancamento.html`): galeria e tabela com as versões (Ranger Black, XL Cabine Simples e Storm)
- **Contato** (`contato.html`): formulário de contato

## O que foi praticado

- Estrutura semântica em HTML
- Layout responsivo com CSS (media queries para celular e computador)
- Tabela comparativa e galeria de imagens
- Dicas ao passar o mouse usando o atributo `title`

## Como abrir

Abra o `index.html` no navegador.
